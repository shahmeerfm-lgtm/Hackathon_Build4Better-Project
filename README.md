##  The Solution

As digital banking, government portals, and online communication become mandatory for everyday life, millions of older or less-experienced users face intense anxiety over making costly mistakes—such as falling for phishing scams, mis-clicking bank transfers, or failing account recovery.

**SafeSandbox** acts as a "flight simulator" for everyday tech. It replicates high-stress online tasks (money transfers, email security checks, and password resets) inside a secure, simulated browser sandbox where users can click around, make mistakes, learn from instant feedback, and build muscle memory without risking a single penny or exposing personal data.

---

##  Key Features

* **Three Real-World Practice Scenarios:**
  1. **Bank Transfer:** Practice verifying recipient names, checking amounts, and reviewing mandatory fee disclosures before hitting send.
  2. **Spotting Phishing Scams:** Learn to analyze suspicious sender addresses, recognize panic-inducing urgency tactics, and choose safe manual app navigation.
  3. **Government Portal Password Reset:** Navigate official `.gov` domains and differentiate between weak passwords and secure passphrases.
* **Interactive Safety Inspector Panel:** A real-time co-pilot sidebar that updates instantly when hovering or clicking elements, offering plain-English security breakdowns and pro tips.
* **Senior-Friendly Accessibility:** High-contrast color palettes, clear labels, step-by-step guidance checklists, and a built-in screen reader guidance mode.
* **Immersive Mode Switching:** Seamlessly toggle between **Guided Step-by-Step Quest** mode and **Free Exploration** mode with smooth UI theme shifts.
* **Polished Feedback Modals:** Smoothly animated success and caution modal popups replacing harsh browser-native alerts.
